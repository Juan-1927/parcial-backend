# parcial-backend

API REST con Express, TypeScript y PostgreSQL que muestra las materias y horarios del semestre.

1. `npm install`
2. Copiar `.env.example` a `.env` y poner los datos de PostgreSQL
3. Ejecutar `database/schema.sql` en la base de datos
4. `npm run dev`

Endpoints: `GET /api/v1/materias` y `GET /api/v1/horarios`
